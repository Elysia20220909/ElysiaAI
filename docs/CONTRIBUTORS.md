## コア貢献者

現在、コア貢献者を募集しています。継続的なコードレビュー、Issue 対応、設計議論、ドキュメント整備に参加してくださる方を歓迎します。

## すべての貢献者

貢献者一覧は [GitHub Contributors](https://github.com/Elysia20220909/ElysiaAI/graphs/contributors) で確認できます。

## 貢献の種類

### コードによる貢献

- 新機能の実装
- バグ修正
- パフォーマンス改善
- リファクタリング
- テストの追加、改善

### ドキュメントによる貢献

- ドキュメントの改善
- チュートリアルの作成
- 翻訳
- コード例の追加
- セットアップ手順や運用手順の補足

### コミュニティへの貢献

- Issue のトリアージとサポート
- Pull Request のレビュー
- Discussions での質問対応
- 利用例や改善案の共有

### その他の貢献

- バグレポート
- 機能提案
- デザインや UI/UX の改善提案
- QA、動作確認、再現手順の整理

## 貢献者になるには

[CONTRIBUTING.md](../CONTRIBUTING.md) を読み、プロジェクトへの貢献方法を確認してください。

小さな修正も歓迎します。タイポの修正、リンク切れの報告、わかりにくい説明の改善も、プロジェクトを確実に良くする大切な貢献です。
