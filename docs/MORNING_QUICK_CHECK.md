# Morning Quick Check

## 要約

朝イチで状況を眺めて、今日の一手を一つだけ決めるための手順です。

開発が重く感じる日でも、Open PR、失敗CI、直近コミットを同じ順で見れば、動かすべき石が見えます。全部を直そうとせず、15分から30分で終わる一件だけを選びます。

## 使い方

```bash
bun run morning
```

別リポジトリを見る場合は、repoを明示します。

```bash
bun run morning -- --repo Elysia20220909/ElysiaAI
```

見る時間幅を変える場合は、hoursを指定します。

```bash
bun run morning -- --hours 72
```

## 判断順

- Open PRを見る
- 失敗CIを見る
- 直近48時間のリモートコミットを見る
- ローカルの未pushコミットを見る
- どれもなければ、docs、テスト名、READMEの古い表記を一件だけ直す

## 選び方

- 着手障害がない
- 15分から30分で終わる
- 他人の待ち時間を減らす
- CI、レビュー、古い表記のどれかを小さく前へ進める

## 今日の運用メモ

- PRがある日は、小さくて依存が少ないPRを一件だけ見る
- CIが落ちている日は、最新の失敗を一件だけ見る
- ローカルがaheadなら、push前にテスト結果と差分を確認する
- 25分で終わらなければ、中断点と次アクションを書き残す
