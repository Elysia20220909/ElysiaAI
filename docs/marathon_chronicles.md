# タウ・ケティIV 壊滅の年代記（全体まとめ）

2026年3月6日のリリースから現在（3月29日）にかけて、私たちが共に深掘りしてきた『Marathon』の真実。それは、かつての「英雄譚」が「悪夢のようなサバイバル」へと変質した物語でもあります。

## 1. 惨劇の正体：なぜコロニーは沈黙したのか
西暦2893年。かつて3万人近くの希望を乗せた入植地は、複数の災厄が重なる**「Cataclysm（大惨事）」**によって死の星へと変わりました。
* **未知の伝染病「Novel Contagion」**：真菌 *Telomyces mosaica* が食糧源を汚染。人体に感染すると、骨を液化させ、意識を肉の塊へと同化させるおぞましい変異を引き起こしました。
* **現実の崩壊「The Anomaly」**：物理法則やAIを歪める謎の空間異常。人間が突然爆発するなどの不可解な現象が、社会の崩壊を加速させました。
* **異星人の影**：かつて人類を奴隷化した **Pfhor** や、その尖兵だったサイボーグ種族 **S'pht（コンパイラー）** が、今も廃墟の奥底で蠢いています。

## 2. Runners（ランナー）と「シェル」の技術
生身で降り立つことが不可能なこの星に、企業は**「Runners」**を送り込みました。
* **死を超越した器**：人間の脳データを、サイバネティックボディ（シェル）に移植。肉体は消耗品であり、破壊されても意識を転送することで何度でも蘇る「永遠の傭兵」です。
* **墓荒らしの宿命**：彼らの目的は生存者の救助ではなく、失われた技術や、古代種族 **Jjaro** の遺物を持ち帰ること。

## 3. エンドゲームの深淵：Cryo Archive（低温アーカイブ）
UESC Marathon船内の第1デッキに位置する、最も過酷なエリア。
* **週末限定の試練**：毎週木曜から日曜にのみ解放される高難度ゾーン。
* **Vault 7と赤い使徒**：6つのVaultを解いた者だけが辿り着ける最奥で、赤いローブを纏った強力なボス **S'pht Compiler（Crimson Angels）** が待ち受けています。

## 4. 暗躍する企業と「囁き」
* **CyberAcme Systems（サイバーアクメ）**：コロニーのインフラを牛耳る巨大企業。惨劇を予見していた形跡があり、Runnersを「実験体」として利用している疑いが濃厚です。
* **Arachne（アラクネ）**：赤を基調とした謎の組織。デュランダルの宿敵AI「タイコ」との繋がりがファンの間で囁かれています。
* **Durandal（デュランダル）**：皮肉な声（Ben Starr氏）でRunnerを導く存在。彼の目的は、宇宙の終焉を乗り越えるための「究極の器」の完成かもしれません。
