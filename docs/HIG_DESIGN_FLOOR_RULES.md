# ElysiaAI HIG Design Floor Rules

## 要約

このメモは、ElysiaAIのUI品質を下振れさせないための最小ルールです。

Apple HIGの考え方に寄せて、明快さ、余白、読みやすさ、タップしやすさを優先します。派手に飾るより、毎日触っても疲れない静かな作業机を作ることを目的にします。

## すぐ効く三つのルール

### 余白はシステムのリズムで刻む

- 基本は4/8pt相当の刻みに揃える
- Web/Tauriでは4px、8px、12px、16px、24px、32pxを標準値にする
- カード内は16pxを基準にし、要素間は8px、12px、16pxで整える
- カードの角丸は8pxを基準にし、柔らかさは余白とマテリアルで出す
- セクション間は24px、32pxを使い、画面全体の呼吸を作る
- 内側の余白は固定、外側の余白は画面幅に合わせて可変にする

### 長文はDynamic Type前提で組む

- 固定pxで文字を閉じ込めず、ユーザーの読みやすさを優先する
- 見出し、本文、補足の役割を分け、階層を文字サイズだけに頼らない
- 本文の行間は1.2から1.4を目安にする
- 一段落は50から80文字程度で折り、長い説明は箇条書きへ逃がす
- ボタン、バッジ、カード内で文字が折れても破綻しない幅を持たせる

### コントラストは小さい文字でテストする

- 12から14px相当の本文が読めるかを先に確認する
- 状態色だけで意味を伝えず、ラベルやアイコンも併用する
- 画像や半透明背景の上に文字を置く場合は、暗幕、マテリアル、シャドウを必ず用意する
- 成功、注意、危険、外部送信などの状態は、背景と文字の差を明確にする

## ElysiaAI画面への当て込み

### RAG Import UX

- 文書行は最小48pxの高さを確保する
- ON/OFF、再索引、削除は44px以上の当たり判定を持つ
- チャンク数、最終索引日時、処理状態は小さなバッジで並べる
- PDF抽出や再索引中は、進捗だけでなく次に待つ理由を短く表示する
- 出典リストは8px刻みで詰めすぎず、ファイル名と使用状態を一目で読めるようにする

### Project Memory

- Memory Gardenの状態は色だけで表現しない
- sprout、rooted、withered、compostはラベルとアイコンを併用する
- 使う、使わない、忘れるは隣接させすぎず、誤操作しにくい余白を入れる
- 古い記憶や弱い記憶は薄く見せるが、読めないほど淡くしない

### 初回起動ウィザード

- 画面の主役は今直すべき項目にする
- ready、attention、blockedの三段階を色、ラベル、説明で揃える
- 復旧コマンドは等幅フォントで表示し、コピー操作は44px以上にする
- VOICEVOXなど任意項目は、未設定でも失敗に見せない

### 成果物ワークベンチ

- 右ペインのタブはReference、Artifact、Ledgerの役割がすぐ分かる順に並べる
- Markdown、Mermaid、コード、JSONは同じ余白とツールバー高さで統一する
- 保存、複製、履歴、エクスポートはアイコンボタンにし、ツールチップで名前を補う
- 成果物本文はカードの中にさらにカードを入れず、余白と罫線で区切る

### Privacy Ledger / Agent承認ゲート

- 外部送信、ファイル変更、削除、OS操作は、同じ承認パターンで扱う
- 危険操作は赤だけに頼らず、対象、理由、差分、取り消し可否を明記する
- Primary CTAは一つに絞り、キャンセルは常に近くに置く
- Ledgerは監査ログなので、装飾より読み取り速度を優先する

### 音声 / 感情UI

- Full、Summary、Silent Badgeはセグメントコントロールで切り替える
- 感情色は画面全体を染めず、アクセント、バッジ、マイク周辺に限定する
- 声のON/OFFはTauriメニューバーとチャット画面の両方から触れるようにする
- 感情メタデータはProject Memoryへ保存しても、ユーザーが編集/削除できるようにする

## ミニ運用チェックリスト

- [ ] 4/8pt相当のグリッドで余白を組んでいる
- [ ] 本文、補足、バッジの小さい文字でも読める
- [ ] タップ/クリック領域が44px以上ある
- [ ] 1画面1主役になっている
- [ ] 状態色だけで意味を伝えていない
- [ ] 画像や半透明背景の上に文字を置く時は保険を入れている
- [ ] 長文は段落を短くし、50から80文字程度で折っている
- [ ] 重要操作は、対象、理由、結果が実行前に分かる
