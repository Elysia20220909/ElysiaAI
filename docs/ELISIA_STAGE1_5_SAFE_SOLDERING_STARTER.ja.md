# E.L.I.S.I.A. Stage 1.5: 安全はんだ付けスターター

## 要約

この文書は、工具あり、はんだ付けありで始めるための **安全な最初の工作ルート** です。

目的は、危険な装置を作ることではありません。低電圧、小電流、机上練習だけで、工具の扱い、はんだ付け、導通確認、LED表示、ケース固定をゆっくり覚えます。

最初に作るもの:

```text
E.L.I.S.I.A. / Mark XLVII Safe Link Indicator

入力: 手動スイッチまたは開発ボードの状態
出力: 低輝度LED 1個
電源: USBまたは小型開発ボードの安全な低電圧出力
目的: LINK ONLINE / SAFE MODE を光で表す
```

## 1. 安全境界

扱うもの:

- 低電圧の開発ボード。
- 練習用ユニバーサル基板。
- LED、抵抗、ピンヘッダ、スイッチ、コネクタ。
- 導通確認。
- 熱収縮チューブ、ケース固定、ケーブル整理。

扱わないもの:

- AC電源、コンセント、電源ユニットの分解。
- 大容量バッテリー、リチウム電池パックの自作。
- モーター、ヒーター、高輝度LED、レーザー。
- 飛行、推進、武器、投射、人体を動かす機械。
- PCマザーボードへの直接はんだ付け。
- 身体に装着した状態での裸基板運用。

## 4. 作業台の作り方

```text
[換気]
   |
[耐熱マット]
   |-- はんだごて + こて台
   |-- 練習基板
   |-- ニッパー
   |-- テスター
   |-- 部品トレー
```

作業前チェック:

- 飲食物を机から外す。
- ケーブルが足や椅子に引っかからないようにする。
- はんだごての置き場所を固定する。
- 作業後に電源を切る流れを決めておく。
- 熱いこて先を置きっぱなしにしない。

## 5. 最初の練習

### 練習1: はんだの点を作る

目的:

- こての熱を怖がりすぎず、丁寧に扱う。
- はんだが丸くなりすぎる、流れない、隣とつながる、という失敗を観察する。

やること:

- 練習基板の何もないパッドに、はんだの小さな点を作る。
- 隣のパッドとつながらないようにする。
- つや、形、量を観察する。

合格:

- 隣のパッドと短絡していない。
- こて先を机やコードに触れさせていない。
- 作業後にこてを安全に戻せる。

### 練習2: ピンヘッダを立てる

目的:

- 部品をまっすぐ固定する感覚を覚える。

やること:

- 練習基板にピンヘッダを差す。
- 1か所だけ仮止めする。
- 角度を確認してから残りをはんだ付けする。

合格:

- ピンが大きく傾いていない。
- 隣のピンとつながっていない。
- 軽く触っても抜けない。

### 練習3: LEDと抵抗を読む

目的:

- LEDには向きがあり、抵抗はLED保護に必要だと理解する。

読むもの:

```text
開発ボードの安全な出力
  -> 抵抗
  -> LED
  -> GND
```

注意:

- LEDを抵抗なしで直接つながない。
- PCマザーボードやUSB電源線へ直接工作しない。
- 最初は開発ボードや学習キットの安全な端子を使う。

## 6. Stage 1.5で作るもの

### Safe Link Indicator

Mark XLVII向けには、`Remote Link` の状態表示として使います。

```text
LINK ONLINE  -> LED ON
LOCAL SAFE   -> LED slow blink
RELAY ALERT  -> LED short blink pattern
```

最初の実装は、実LEDがなくても構いません。

進め方:

1. ブラウザ版でLED表示をシミュレーションする。
2. micro:bitや開発ボード内蔵LEDで同じ状態を表示する。
3. 練習基板にLEDと抵抗をはんだ付けする。
4. ケースに入れて、むき出しの金属部分を減らす。

## 7. テスターで見る場所

最初に使うのは、導通確認だけで十分です。

確認すること:

- 隣のピン同士が意図せずつながっていない。
- GNDに落とす線が予定どおりつながっている。
- コネクタの向きが間違っていない。
- はんだ付けした場所がぐらつかない。

避けること:

- 通電中の測定を最初の練習にしない。
- AC電源や電源ユニットを測らない。
- バッテリーの内部や充電回路を測らない。

## 8. 合格条件

Stage 1.5完了の条件:

- はんだごてを安全に置ける。
- 練習基板にきれいなはんだ点を作れる。
- ピンヘッダを1列まっすぐ固定できる。
- LED、抵抗、GNDの関係を説明できる。
- テスターで短絡がないことを確認できる。
- 低電圧、小電流、机上デモの範囲を守れている。
- 危険な電源、モーター、発熱部品へ進んでいない。

## 9. 次の段階

Stage 1.5の次は、目的で分けます。

| 方向 | 次 |
| --- | --- |
| Mark XLVIIらしくしたい | Remote Link IndicatorをブラウザHUDと同期する |
| 電気図面を読めるようになりたい | LED + 抵抗 + スイッチの回路図を描く |
| 見た目を整えたい | 小型ケース、ラベル、ケーブル整理 |
| micro:bitから進めたい | 開発ボード内蔵LEDから外付け低輝度LEDへ |

4方向をまとめて進める場合は、`docs/ELISIA_MARK47_STAGE2_REMOTE_LINK_INDICATOR.ja.md` を使います。

工具を持つというのは、急に危ない世界へ入ることではありません。小さな熱、小さな光、小さな確認を積み重ねることです。最初の一滴のはんだが落ち着いて光れば、そこから本当の工作が始まります。
