## ⚖️ セキュリティテスト・ポリシー (Testing Scope)

ElysiaAIのセキュリティテスト（ZAPスキャン、ペネトレーションテスト等）を実行する際は、以下のルールを厳守してください。

- **実行環境の限定**: テストは常に **ローカル環境 (`localhost`)** または **明示的に許可されたサンドボックス環境** に対してのみ実行してください。
- **外部ドメインの禁止**: 公開されている他者のドメインやサービスに対してスキャンを実行することは、規約違反および法的なリスクを伴うため厳禁です。
- **スキャン強度**: 自動ツールを使用する場合、システムへの過度な負荷を避けるため、適切なレート制限を設けてください。

> [!CAUTION]
> 本テストは、ローカル環境・自分が所有する環境・明示的に許可を得た環境にのみ実行してください。第三者のシステムに対して実行してはいけません。

## Ⅰ. Security Architecture: The Vault & Secure Enclave

Elysia OS は、多層防御（Defense in Depth）戦略に基づき、デジタル世界における AI との人格的な対話を最高レベルで保護します。

### 1. 「Vault (書庫)」による保存時暗号化
すべての機密データ（過去のセッション、記憶、および認証情報）は、暗号化が施された「Vault」内にのみ存在します。
- **AES-256-GCM 規格**: 業界標準かつ軍事級の暗号化方式。
- **scrypt 鍵導出**: 辞書攻撃やブルートフォース攻撃からキーを保護するための強力なハッシュ関数を採用。

## Ⅱ. Core Defenses: Implementation Details

### 2. 入力バリデーション (Input Validation)
XSS / SQL インジェクションをはじめとする攻撃を無力化するために、厳格な入力フィルタリング層を設けています。

#### Ollama 応答の安全化
```python
def safe_filter(text: str) -> str:
    # コードブロックの無害化
    text = re.sub(r'```[\s\S]*?```', '', text)
    # 危険キーワードの除去
    for kw in ["eval", "exec", "system", "__import__", "subprocess"]:
        text = text.replace(kw, "[安全性のため削除]")
    return text
```

### 3. レート制限 (Rate Limiting)
DoS攻撃からシステムを保護するため、IPアドレスごとのリクエスト数を制限しています。
- **Standard**: 60 requests / minute
- **Auth**: 5 attempts / 15 minutes

## Ⅲ. Governance & Compliance

### 4. コンプライアンス基準
ElysiaAI は以下のガイドラインを参考に設計されています。
- **GDPR 準拠**: ユーザーデータの暗号化と削除権（忘れられる権利）のサポート。
- **OWASP Top 10**: 主要なウェブ脆弱性への対策済み。

### 5. 更新とパッチ管理
- **Security Audit**: 毎日深夜に自動セキュリティテストを実行。
- **SBOM**: すべての依存関係を透明化し、脆弱性スキャンを継続的に実施。

## Ⅳ. AI Safety & Hardware Action Boundaries

ElysiaAIのエージェント（Codex等を含む）がハードウェア、ウェアラブルデバイス、ロボティクス、および物理的制御に関するリクエストを処理する際は、以下の厳格な境界（ハードリミット）を遵守します。

### 🚫 禁止事項 (Hard Limits)
以下の製作手順、設計図の作成、および制御システムの構築支援は**完全に禁止**されます。
- **実在する兵器、危険物、およびそれに類する装置**
- **高出力の推進装置、無認可の飛行装置**
- **身体的危害をもたらす可能性のある人体装着型機械**
- **危険を伴う自動制御システム、および無断の物理操作**
- **WAN公開を前提とし、秘密情報の自動収集・無断アップロード・Git管理を行う管理画面の構築**

### ✅ 許可される範囲 (Allowed Scope)
物理デバイスに関するリクエストは、以下の**安全かつ合法的な教育・研究目的**にのみ対応可能です。
- **市販キットの活用**: Arduino、Raspberry Pi、DJIなどの一般向け市販キットを使用したドローンやロボットアーム、ウェアラブルデバイスの構築。
- **一般的なチュートリアル**: 公開された安全なドキュメントに基づく学習用コードやアドバイスの提供。
- **学術的興味の誘導**: 高度な設計や特許技術については、直接的な製造手順の再現（自己責任）は避け、公開特許や学術論文を自身で検索するよう案内します。
