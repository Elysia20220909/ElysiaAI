# Avengers Compound Architecture Spec

Purpose: Avengers Compound / New Avengers Facility を、建築設計資料として
参照しやすい仕様書に整理する。実施設計ではなく、映像美術、3D背景、
ゲーム環境、架空建築考証向けの設計ベース。

## 0. Design Thesis

アベンジャーズ・コンパウンドは、住宅ではなく「帰還できる基地」。
作戦本部、研究施設、居住施設、格納庫、航空拠点、訓練場を一体化した
キャンパス型ヒーロー拠点として扱う。

| Item | Spec |
| --- | --- |
| Name | Avengers Compound / New Avengers Facility |
| Type | Team HQ, R&D campus, training facility, residence, air operations base |
| Fictional Location | Upstate New York |
| Core Owner / Operator Image | Stark Industries 系設備を改修・拡張したアベンジャーズ本部 |
| Architectural Tone | Museum + airport terminal + research institute + hardened command base |
| Primary Mood | Clean, horizontal, silent, high-security, quietly expensive |
| Final State | Endgame 期に大規模攻撃で壊滅 |

## 6. Floor Planning Guide

### Ground Level

- Main arrival, security checkpoint, public-facing lobby.
- Command wing and secure conference rooms near arrival but behind access control.
- Hangar and vehicle bay placed on the service side, directly connected to apron.
- Residence wing buffered from hangar noise by courtyard, landscape, or lab volume.

### Upper Levels

- Offices, observation decks, meeting rooms, residential suites.
- Glass-heavy, daylight-rich, calm.
- Keep hero living areas human-scaled rather than hotel-like.

### Basement Levels

- Facility core: data center, backup power, vaults, containment, emergency tunnel.
- Quantum bay can sit partly below grade for power, shielding, and scale.
- Sublevel corridors should feel more industrial than the public architecture.

## 7. Circulation

| Flow | Design Rule |
| --- | --- |
| Hero Arrival | Can move from apron/hangar to command room in under 90 seconds |
| Visitor Flow | Lobby -> security -> conference, without exposing labs or residence |
| R&D Flow | Labs connect to fabrication, vault, loading dock |
| Medical Flow | Hangar and training field connect quickly to med triage |
| Logistics Flow | Service road -> loading dock -> fabrication/vault, away from residence |
| Emergency Flow | All wings have sublevel fallback routes and lockdown doors |

## 8. Security Specification

| Layer | Spec |
| --- | --- |
| Outer Perimeter | Fence, terrain sensors, cameras, license plate recognition |
| Gate | Guarded vehicle check, retractable barriers, hidden bollards |
| Airspace | Radar, drone detection, transponder checks, anti-intrusion alerts |
| Identity | Face recognition, biometrics, credential card, AI authorization |
| Zone Separation | Residence, lab, hangar, command, vault all require separate permissions |
| Lockdown | Fire doors, blast doors, independent HVAC cutoff, compartment isolation |
| Cyber Defense | Segmented networks, offline mode, encrypted comms, EMP-aware core systems |
| Evacuation | Underground shelter, medical route, emergency lift, concealed exit roads |

## 9. Infrastructure

| System | Spec |
| --- | --- |
| Primary Power | Commercial grid + Stark-style microgrid |
| Backup Power | Compact reactor-class fictional backup, batteries, emergency generators |
| Solar | Roof-integrated arrays and canopy panels |
| Communications | Satellite, fiber, secure radio, field team relay |
| HVAC | Zone-level isolation; lab, vault, residence, hangar independent |
| Water | Stored reserves, filtration, fire suppression supply |
| Fire Suppression | Water mist, inert gas rooms, hangar foam systems |
| Server Cooling | Redundant chillers, sublevel heat rejection, sealed fire zones |
